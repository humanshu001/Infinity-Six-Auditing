# Access Control Attacks results

Summary of implemented tests and expected outcomes:

- Non-DAO calls DAO functions: expect revert (only DAO allowed).
- Non-system calls `mint()`: expect revert (only system contract allowed).
- Old DAO calls after DAO update: expect revert (old DAO loses privileges).
- DAO updates itself repeatedly: allowed when performed by current DAO/new DAO.
- DAO sets system contract to arbitrary address: allowed by DAO.
- DAO cannot set zero address: expect revert.
- Whitelist toggle: DAO can grant and revoke whitelist; mapping reflects changes.
